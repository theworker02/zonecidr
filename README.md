# zonecidr

Zone identifiers and cidr tokens for idempotent workflows.

**Site:** https://theworker02.github.io/zonecidr/

## Install / run

```bash
git clone https://github.com/theworker02/zonecidr.git
cd zonecidr
node src/cli.js
node --test
```
